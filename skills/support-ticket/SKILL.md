1. Official site only: the OFFICIAL SUPPORT/COMMUNITY address Bah gives. Never a third-party "support" site.
2. Start the flow: "Get Support" / "Contact Support" / "Create a request". Pick the product from the site's list ("Choose a product" → Mac), then the topic, then "Get more help" / contact options — not the search box. Never install a helper app (e.g. SupportAssist).
3. Sign-in form → Bah pauses for the user. Never type a password or create an account. After RESUME the user is signed in: carry on, do not finish.
4. Product: the one the user named. Serial number / service tag unknown → ask the user; never invent it.
5. Category: the closest to the problem (battery, fan, display…).
6. Description: the user's words only — symptoms, when it started, what they tried.
7. Contact details: only USER CONTACT or the request. Contact method (chat, phone, email, call): ask unless the request says.
8. Forum post: search the community first; a matching thread → report its link and ask the user. Otherwise draft the title and post.
9. Final Submit / Send / Post: Bah shows the user the text and asks. Cancelled → stop and report what is filled.
10. Report what was filled and the case number or post link.
