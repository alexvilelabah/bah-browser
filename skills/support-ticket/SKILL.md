1. Stay on the official support site Bah gives; never another site.
2. Start: "Get Support" / "Contact Technical Support". Pick the product, then the topic, then contact options. Never install a helper app.
3. Page did not load (Access Denied / 403, not found, blank, dead click): do not retry it or get around a block. web_search for that page (e.g. "Dell contact technical support XPS 13"), open a result on the vendor's domain. Still blocked → stop, tell the user.
4. Sign-in form → Bah pauses for the user. Never type a password or create an account. After RESUME: carry on.
5. Serial number / service tag unknown → ask the user; never invent it.
6. Description, subject, contact, serial: Bah fills them from what the user said; the user reviews. FORM FILLED BY BAH → do not retype them. Otherwise the user's words only.
7. Contact: only USER CONTACT or the request; contact method: ask unless given.
8. Forum post: search the community first; a matching thread → report its link and ask the user. Otherwise draft the title and post.
9. Final Submit / Send / Post: Bah shows the user the text and asks. Cancelled → stop.
10. Report what was filled and the case number or post link.
