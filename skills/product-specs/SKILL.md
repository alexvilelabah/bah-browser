Official specs beat any shop listing. Find the manufacturer's own page for the EXACT model.
1. Use web_search for "site:<maker domain> <exact model> specifications" (e.g. site:lenovo.com IdeaPad 3 15ADA05 specifications) and open the result on the maker's own domain (spec sheet, product reference, or support page). Prefer this over the maker's home-page search box, which often shows trending/marketing items first. Model names are precise — "15ADA05" is not "15IIL05".
2. Spec pages are usually split into sections or TABS (Overview, Specifications, Models, Accessories, Parts, Downloads). The overview rarely has power details: open "Specifications" for the power adapter line (watts, connector/tip size or USB-C), and "Accessories" or "Parts" for compatible part numbers.
3. Use find "adapter" / "power" / "battery" on long pages instead of scrolling blindly.
4. One model name can cover several variants (machine type, region, CPU); if the part differs by variant, note each.
5. store the facts (part numbers, watts, voltage, connector) before leaving the site — you will compare shop listings against them.
