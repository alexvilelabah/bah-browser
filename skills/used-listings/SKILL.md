Secondhand options: online marketplaces (auctions or fixed price, shipped) and local classifieds (pickup).
1. Search with the part number or exact model when you have one. Use the site's filters for "Used" condition and for lowest price + shipping when available.
2. For each listing read: title, price, shipping (total = price + shipping), condition (new / used / for parts), auction vs buy-now (bids, time left), seller rating or location and date posted.
3. Keep only listings that name the model, part number or exact specs; skip "for parts / not working" unless asked.
4. Local classifieds are organized by city: use the city the user named, or the major city for the USER'S REGION time zone, and say which one you used.
5. Few or no matches is a normal result — report it. Never bid, buy, message sellers or share personal info.
